# ELEVATELABS_TASK08
Interactive Power BI dashboard showcasing sales and profit analysis by month, region, and category using a sample Superstore dataset.

## 📊 Dashboard Features

- **Total Sales & Profit Cards**: Quick KPIs for total performance
- **Line Chart**: Sales trends over months (Jan–Dec 2023)
- **Bar Chart**: Sales by Region
- **Clustered Column Chart**: Sales vs Profit by Region
- **Bar Chart**: Profit by Category
- **Slicers**: Dynamic filtering by Order Date, Region, and Category

## 📁 Included Files

- `SUPERSTORE2.pbix`: Power BI report file  
- `Sales_Dashboard_Report.pdf`: Exported snapshot of the dashboard  
- `Superstore_Sales.csv`: Custom dataset with 100 entries  

## 🔍 Key Insights

1. **East Region** had the highest sales (~28K), followed closely by West and Central.  
2. **Office Supplies** generated the highest profit (~2.6K), slightly ahead of Technology.  
3. **South Region** had the lowest sales and the second-highest profit, indicating better margins.  
4. Sales were highest in **May and November**, with several noticeable dips mid-year.
